# Handoff

Travail en cours laissé par la session précédente. Une section `## AAAA-MM-JJ` = un
offload à reprendre ; la session qui le reprend **supprime** la section (la suppression
vaut accusé de réception). Aucune section datée = rien en cours.

Ce qui reste vrai dans un mois n'a rien à faire ici : une action réelle → `shipkit ask`,
une question de conception → `06-backlog.md`, une règle → la page qui la possède.
